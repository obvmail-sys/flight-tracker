# Трекер цен на авиабилеты

Сайт: https://obvmail-sys.github.io/flight-tracker/ — поля «Откуда / Куда»; для
направлений «туда» и «обратно» отдельно: точечный график «дата вылета → цена»
с линейным трендом и таблица всех найденных рейсов.

Данные: Travelpayouts Aviasales Data API, `aviasales/v3/prices_for_dates`, EUR
(кэш Aviasales 2–7 дней).

## Вкладки (маршруты)

Каждая вкладка сайта — файл `routes/<id>.json`:

```json
{ "name": "Барселона", "from": ["HEL"], "to": ["BCN", "GRO", "REU"] }
```

`from`/`to` — один или несколько аэропортов (группа). Добавлять удобнее с сайта:
кнопка «＋» → выбрать аэропорты с подсказками → «Сохранить на GitHub» → на GitHub
нажать «Commit changes». Сохранение сразу запускает сбор (1–2 минуты).
Удаление — «Удалить вкладку» на сайте.

## config.json

```json
{ "collect_days_min": 0, "collect_days_max": 180 }
```

Окно дат вылета для сбора: от сегодня до сегодня+180 дней.

## Как устроено

- `fetch.py` (Python 3.10+, без зависимостей) — для каждой пары аэропортов всех
  вкладок запросы в одну сторону (`one_way=true`) туда и обратно, по месяцам окна;
  проверяет коды по справочнику аэропортов Travelpayouts.
- `data/legs/<FROM>-<TO>.json` — история цен по направлению. Одна запись = рейс + цена; если та же цена
  встречается снова, обновляется только `last_seen_at`. Файл пишется атомарно,
  при ошибках API не трогается.
- `data/last_run.json` — статус последнего запуска: вкладки, коды, найдено, ошибки.
- `data/airports.json` — компактный справочник аэропортов для подсказок на сайте.
- `.github/workflows/ticker.yml` — «таймер»: запускает сбор, ждёт 4 часа и
  перезапускает себя (расписание GitHub ненадёжно). Его cron — запасной перезапуск.
- `.github/workflows/fetch.yml` — сам сбор; также просыпается каждый час (GitHub иногда пропускает
  запуски по расписанию), собирает, если с прошлой проверки прошло ≥ 3,5 ч;
  ручной запуск — всегда. Коммит данных.

Сайт статический, поэтому живого запроса к API из браузера нет (токен стал бы
публичным) — он показывает данные, собранные по расписанию.

Локально: `TRAVELPAYOUTS_TOKEN=... python3 fetch.py`, затем `python3 -m http.server`.
